# ⚡ Electricity Billing System

A Java-based desktop application designed to manage electricity billing operations. Developed using Java Swing for the user interface and JDBC for database connectivity, this system enables administrators to manage customer details, generate and calculate bills, and process payments.

## 🛠️ Features

- Admin & User Login System  
- Generate and View Electricity Bills  
- Calculate and Pay Bills  
- Add/View/Update Customer Details  
- Meter Information Management  
- View Deposit and Billing History  
- Integrated Paytm Payment Simulation  
- GUI built with Java Swing  
- Database integration using JDBC

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or later  
- MySQL (or equivalent RDBMS)  
- NetBeans IDE (Recommended)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/Electricity-Billing-System.git
   ```

2. **Open in NetBeans**:
   - Open NetBeans.
   - Go to `File > Open Project`, and select this folder.

3. **Configure the database**:
   - Edit `Conn.java` with your MySQL username, password, and database details.

4. **Run the project**:
   - Right-click the project in NetBeans and select `Run`.
